## What to Do

- **Fill in column C (Spanish)** — that is your only column to edit
- Column A is the key (internal ID — ignore it)
- Column B is the English source text — use it as your reference
- If a row already has Spanish text in column C, you can review and correct it, but you don't need to re-translate it
- If you are unsure about a translation, **leave it blank** — it is better to leave it empty than to guess

---

## What NOT to Do

- **Don't edit columns A or B** — keys and English text are locked references
- **Don't delete any rows**
- **Don't add new rows**
- **Don't translate HTML tags** — if you see tags like strong, br, or a href, copy them exactly as written into your translation. Only translate the human-readable words around them.

**Example:**

> English: Call your **state representative** today
> Spanish: Llame a su **representante estatal** hoy
>
> The bold tags wrapping "state representative" stay exactly the same in both versions.

## Special Cases

### Acronym keys (one-sheet tab)

Some keys under `acronym.*` have English values like:

> `abor (Independent Contractors)`

This is intentional. The first letter of each word in the acronym "LABOR" is rendered as a styled character on the website — so the sheet only stores the *rest* of the word. Translate the full word naturally:

- `abor` → `Trabajo` (the "T" will be rendered separately on the site)
- `abor (Independent Contractors)` → `Trabajo (Contratistas Independientes)`

### Parenthetical definitions

Many keys include a parenthetical like `(Independent Contractors)` or `(Retaliation)`. Translate the full phrase including the parenthetical.
